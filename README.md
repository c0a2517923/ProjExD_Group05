# ★麻辣湯★

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1

## ゲームの概要
* 麻辣湯屋さんの店員になって、お客さんの要望通りのメニューを作るゲーム

## ゲームの遊び方
* お客さんの注文に対して、商品棚から対応する具材を数字キーorクリックで選んで、ボウルに入れる。
* 辛さを指定された場合は、上下キーで辛さを変更する（3段階）。
* 制限時間内にすべてのお客さんを捌く。
* たくさんのお客さんに提供できるとその分評価が上がる。
* Gameoverになると、そこまでの評価が表示される（★～★★★）。

## ゲームの実装
### 共通基本機能
* 背景画像の表示

### 分担追加機能
* お客さん来店機能（担当: 南風原） : お客さん（こうかとん）を表示、吹き出しに入れてほしい具材と辛さの箇条書きを表示させる。
* 提出したメニューの判定（担当: 鈴木） : 提出された料理の判定
* スコア機能（担当: 波多江） : 完璧にお題を達成したら、点数が追加される
* 時間機能（担当: 仲林） : 画面に残り時間を表示
* 操作方法の表示（担当: 仲林） : 簡単に操作方法を画面に表示する
* 残機（担当: 徳安） : お客さんに提供できなかったら残機が1減る、残機がなくなったらGameover画面を表示
* お客さんのボウル表示（担当: 南風原） : お客さんが持っているボウルを表示

### 時間機能の実装（担当: 仲林）
* Timeクラスで制限時間を管理する。
* 制限時間は60秒に設定する。
* update(dt)で経過時間に応じて残り時間を減らす。
* 残り時間が0秒になるとタイマーを停止する。
* draw(screen)で残り時間を画面に表示する。
* 日数経過と時間のリセット機能も用意する。
### 操作方法の表示の実装（担当: 仲林）
* Helpクラスで操作説明画面を管理する。
* Qキーで操作説明画面の表示・非表示を切り替える。
* 半透明の黒い背景に操作方法を表示する。
* 操作説明を表示している間はタイマーを一時停止する。
